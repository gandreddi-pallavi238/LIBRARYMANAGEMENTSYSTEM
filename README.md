## 📚 Library Management System (Java Console Application)

A simple Console-Based Library Management System built using Core Java, demonstrating concepts like OOP, classes & objects, methods, ArrayList, control structures, and modular programming.

This project is ideal for beginner to intermediate Java learners.

## 🚀 Features
# 📘 Book Management

Add new books

View all books

Issue a book

Return a book

Track book availability (Issued / Available)

# 👤 Member Management

Add library members

View all members

# 🧠 Core Concepts Used

Object-Oriented Programming

Classes & Objects

Methods

Encapsulation

ArrayList Collections

Loops and switch-case

Scanner for user input

## 🗂️ Project Structure
LibraryManagementSystem/

 │
 ├── Book.java        # Book class with id, title, author, issued-status
 
 ├── Member.java      # Member class for user data
 
 ├── Library.java     # Core operations (add/view/issue/return)
 
 └── Main.java        # Main menu and program execution

📄 How It Works
1️⃣ Main Menu

When you run the program, you get this menu:

1. Add Book
2. Add Member
3. View Books
4. View Members
5. Issue Book
6. Return Book
7. Exit

2️⃣ User selects an operation

The system performs actions like:

Add a new book

Register a member

Issue or return a book

Display lists
